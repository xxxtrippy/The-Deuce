Flashes bootloader + partitions + app by region — your SD data and saved settings are preserved.
How to update
  1. Plug the Deuce into this computer with a data USB cable.
  2. Click Flash / Update above.
  3. Pick the Deuce's serial port in the browser prompt (hold BOOT if it won't connect).
  4. Wait for "Flashing complete", then the Deuce reboots into the new build.
Latest build is published automatically every time CI finishes on main.
